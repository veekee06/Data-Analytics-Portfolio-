SQL Query Practice Project

Project Overview

This project focuses on practicing and applying SQL (Structured Query Language) concepts to retrieve, analyze, and manipulate data from a relational database.

The project involved writing different SQL queries to solve database-related tasks such as filtering records, performing joins, using aggregate functions, and applying conditional statements. The queries were tested and documented alongside screenshots of the outputs generated from the database management system.

During a later class session, the tutor reviewed the work and provided corrections and feedback to improve query structure, syntax accuracy, and overall understanding of SQL concepts.

Objectives

The objectives of this project were to:

* Practice writing SQL queries
* Understand relational database operations
* Retrieve meaningful information from database tables
* Apply SQL clauses and functions correctly
* Improve query formatting and optimization skills
* Learn from tutor corrections and feedback

Tools Used

Software

* SQL Server Management Studio (SSMS)
* Microsoft Word

SQL Concepts Applied

The project covered several important SQL operations and concepts, including:

* SELECT statements
* WHERE clauses
* JOIN operations
* LEFT JOIN
* Aggregate functions:
    * AVG()
    * MIN()
    * MAX()
* Conditional statements using CASE
* GROUP BY
* Aliasing using AS
* Handling NULL values using COALESCE

Sample Tasks Performed

Question 1 – Employee Information Retrieval

A query was written to retrieve employee information from related tables using joins.

Operations Used

* SELECT
* JOIN
* Aliasing

Purpose

To combine records from multiple tables and display employee details in a single result.

Question 2 – Salary Analysis

Queries were created to calculate:

* Average salary
* Minimum salary
* Maximum salary

grouped by occupation.

Operations Used

* Aggregate functions
* GROUP BY

Purpose

To analyze salary distribution across occupations.

Question 3 – Salary Filtering

A query was written to retrieve employees earning above a specified salary threshold.

Operations Used

* WHERE clause

Purpose

To filter records based on salary conditions.

Question 4 – Handling Missing Data

A query used COALESCE to replace NULL occupation values with a default label.

Operations Used

* LEFT JOIN
* COALESCE

Purpose

To improve data readability and manage incomplete records.

Question 5 – Conditional Bonus Eligibility

A query applied conditional logic using CASE statements to determine employee bonus eligibility based on department rules.

Operations Used

* CASE
* Conditional expressions
* Joins

Purpose

To classify employees according to predefined business rules.

Learning Outcomes

Through this project, the following skills were developed:

This project provided practical experience in querying relational databases using SQL. It demonstrated the use of essential SQL operations for data retrieval, analysis, and manipulation.
