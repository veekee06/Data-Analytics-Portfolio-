Project Overview

This project focused on analyzing retail sales data using Microsoft Excel to uncover insights into product performance, customer demographics, and monthly sales trends. The dashboard was built using Pivot Tables to transform raw retail data into an interactive visual report. 
The analysis aimed to identify high-performing product categories, understand customer purchasing behavior, and monitor sales performance over time. 


Tools Used
* Microsoft Excel
* Pivot Tables
* Data Visualization
* Dashboard Design


Dataset Description

The dataset contained retail sales records including:
* Product categories
* Customer age groups
* Gender demographics
* Monthly sales data
* Revenue figures

Dashboard Features
1. Top Product Category Analysis:

A bar chart and pie chart were created to compare sales contributions across:
* Electronics
* Clothing
* Beauty Products

Key Insight

Electronics and Clothing generated the highest sales percentages, while Beauty products contributed a slightly smaller share.

2. Customer Demographic Breakdown

The dashboard analyzed customer purchasing patterns based on:
* Age groups
* Gender

Key Insight

Customers aged 46–60 represented one of the strongest purchasing groups across both genders.

3. Monthly Sales Trend

A line chart was used to track monthly sales performance throughout the year.

Key Insight

Sales fluctuated across different months, indicating seasonal trends and varying customer demand patterns.

Role of Pivot Tables

Pivot Tables were used to:
* Summarize sales data
* Group customer demographics
* Calculate sales totals and percentages
* Create interactive dashboard charts

They served as the foundation for all dashboard visualizations.

Business Recommendations
* Focus marketing efforts on high-performing product categories
* Develop targeted campaigns for dominant customer age groups
* Prepare inventory ahead of peak sales periods

Conclusion

This project demonstrates practical Excel skills in:
* Data analysis
* Dashboard development
* Data storytelling
* Business insight generation

The dashboard successfully transformed raw retail data into meaningful visual insights for decision-making.
